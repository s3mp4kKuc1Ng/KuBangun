---
name: Renovation comparisons
description: Explicit classification and pairing requirements for renovation measurements
---

Renovation measurements must be explicitly classified by the user as existing or proposed and explicitly paired. Never infer these from project mode, room names, document labels, or matching dimensions. Legacy records remain unclassified until the user chooses a state.

**Why:** The requested renovation workflow preserves old records without silently assigning them a physical state. An unlabeled measurement cannot establish whether it describes the current room or a plan.

**How to apply:** Preserve dimensions and source evidence when loading older records. Keep unclassified or unpaired rooms visible; show unavailable differences rather than treating a missing counterpart as zero. Comparing room dimensions remains a geometric illustration, not a structural adequacy claim.
